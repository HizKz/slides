# 私の開発環境

部内LT向けに、普段の開発ツールとタスク管理を紹介する約10分のスライドです。

リポジトリ直下から生成します。

```sh
marp --html --allow-local-files --theme template/themes/mint.css presentations/my-dev-environment/slide.md --pdf -o presentations/my-dev-environment/slide.pdf
marp --html --allow-local-files --theme template/themes/mint.css presentations/my-dev-environment/slide.md -o presentations/my-dev-environment/slide.html
```

資料: [dotfiles](https://github.com/HizKz/dotfiles)、[TimeBlocker](https://github.com/HizKz/TimeBlocker)

画像: [WezTerm公式の画面例](https://wezterm.org/screenshots/two.png)、[Karabiner-Elements公式の設定画面例](https://karabiner-elements.pqrs.org/docs/manual/configuration/configure-simple-modifications/)、TimeBlockerリポジトリ内のアプリアイコン。
